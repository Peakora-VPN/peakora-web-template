# CLAUDE.md

Инструкции для Claude Code при работе с этим репозиторием.

Актуальные правила проекта находятся в [`AGENTS.md`](./AGENTS.md) и применяются
полностью: FastAPI + Jinja2, Python 3.15, uv + Docker, явные routes, loopback-only
backend и неизменные специальные маршруты Remnawave. Этот файл намеренно короткий,
чтобы две копии инструкций не расходились при следующих изменениях.
