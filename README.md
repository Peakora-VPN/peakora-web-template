# peakora-web-template

Статический сайт, который nginx отдаёт на домене узла Peakora Network. Один
артефакт на все локации: страна определяется в браузере из имени хоста, список
узлов нигде не публикуется.

`pl.peakora.network` покажет «Poland · Edge node», `de.peakora.network` —
«Germany · Edge node», неизвестный поддомен — нейтральное «Edge node». Правок
шаблона при добавлении ноды не требуется.

## Сборка

```bash
node build.mjs      # собирает dist/
node --test         # прогоняет проверки
```

Зависимостей нет — ни рантайм, ни сборочных. Нужен только Node 20 или новее,
и только на машине разработчика: на ноде лежит уже собранный `dist/`.

## Установка на ноду

```bash
git clone <repo> /opt/peakora-web-template
cd /opt/peakora-web-template
sudo deploy/install.sh
```

Установщик кладёт `dist/` в `/var/www/html`, ставит фрагмент в
`/etc/nginx/snippets/peakora-node.conf`, проверяет конфигурацию через `nginx -t`
и перезагружает nginx. Если проверка не прошла, фрагмент откатывается, а скрипт
завершается с ненулевым кодом. Флаги: `--root DIR`, `--no-snippet`.

Одну строку в конфигурацию ноды нужно вписать руками — блоки `server` на разных
нодах различаются, и автоматическая правка чужого конфига опаснее ручной:

```nginx
server {
    server_name pl.peakora.network;
    listen unix:/dev/shm/nginx.sock ssl proxy_protocol;
    http2 on;

    ssl_certificate     "/etc/nginx/ssl/peakora/fullchain.pem";
    ssl_certificate_key "/etc/nginx/ssl/peakora/privkey.pem";

    include /etc/nginx/snippets/peakora-node.conf;
}
```

Строки `root`, `index` и `add_header` из блока при этом убираются: их задаёт
фрагмент. Он же добавляет то, чего в блоке не было: свою страницу 404 вместо
дефолтной страницы nginx с номером версии, кэширование ассетов и заголовки
безопасности.

Обновление: `git pull && sudo deploy/install.sh`.

## Что нужно проверить перед запуском

Ящик `abuse@peakora.network` из футера должен реально принимать почту:
отбивающийся abuse-адрес выглядит хуже, чем его отсутствие. Адрес правится в
двух местах — константа `CONTACT_EMAIL` в `src/lib.js` и ссылка в
`src/index.html`.

## Обновление шрифтов

```bash
node tools/fetch-fonts.mjs > faces.tmp.css
```

Скрипт перекачивает подмножества с Google Fonts в `src/assets/fonts/` и печатает
готовый блок `@font-face`, который заменяет собой такой же блок в начале
`src/styles.css`. В сборке он не участвует и запускается вручную.

## Правила, которые ломать нельзя

- **Никаких внешних запросов со страницы.** Сайт открывается из стран с
  блокировками: внешний CDN может не ответить, и вместо нормальной страницы
  посетитель увидит поехавшую вёрстку.
- **Никаких инлайновых `<script>` и атрибутов `style=`**: страница работает под
  `Content-Security-Policy: default-src 'self'`.
- **Никаких проверяемо-ложных утверждений в текстах** — ни номера автономной
  системы, ни PeeringDB, ни юрлица, ни метрик.
- **Список локаций не публикуется ни в каком виде.**

Всё перечисленное, кроме последнего пункта про тексты, проверяется тестами
в `tests/`. Подробности и обоснования — в
[`CLAUDE.md`](./CLAUDE.md) и в спеке `docs/superpowers/specs/`.
