## Установщик расширяет доступ к посторонним файлам

**Средний риск при общем корне сайта.** После копирования файлов установщик присваивает права 0755 каталогам и 0644 файлам во всём дереве назначения. Если оператор укажет каталог с существующими приватными файлами, они станут доступны для чтения другим локальным пользователям, а файлы под публичными URL сможет отдать nginx. Права следует задавать только для установленных из `dist/` путей. [deploy/install.sh](../../deploy/install.sh#L90)
